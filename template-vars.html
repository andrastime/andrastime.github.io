Email Template Variables

Placeholders you can drop into an A/B email template body or subject line. Each {%…%} tag is replaced per-lead when a kickoff draft is rendered.

Variable What it becomes
{%new_site_link%} Link to the newly generated demo site (the recipient-facing URL).
{%old_site_link%} The lead's existing website URL.
{%old_site_pic%} A screenshot of their current site. See the caveat below.
{%new_site_pic%} A hosted screenshot of the newly generated demo site — recipient-reachable, unlike {%old_site_pic%}.
{%upsell_list%} The generated upsell / gap checklist for that lead.
{%gaps_summary%} The gap / opportunity list — same content as {%upsell_list%}; mirrors the naming used by the default generation script.
{%company_name%} The lead's business name.
{%company_type%} The business type — the lead's specialization, else its category, else "local business".

Caveat: {%old_site_pic%}

Heads up. {%old_site_pic%} points at a 127.0.0.1 URL that only you can load, so in the seeded template it's a small secondary "your current site" thumbnail — the recipient-facing image is the cid:demo demo screenshot. Edit the template body in the A/B Tests tab if you want to drop that line.
